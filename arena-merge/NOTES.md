# arena-merge — notes for agents

Two versions side by side while the port is tested:
- **Live:** single file `arena-merge/index.html`, copied to `docs/arena-merge.html` (Pages). Untouched by the port.
- **Port (2026-10-22, untested on real are.na data):** `arena-merge/src/` built by `node build.js` into `arena-merge/dist/arena-merge.html`. **Do not run `node build.js --docs` (or `npm run build -- --docs`) until Kim has tried the port on her test channels: it overwrites `docs/arena-merge.html`.**
